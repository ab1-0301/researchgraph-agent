# ResearchGraph Agent — 产品设计图

> 面向海外学生和研究者的 AI 研究笔记图谱智能体

## 1. 完整工作流

```
                         ┌──────────────────────────────────────┐
                         │          用户上传/粘贴材料           │
                         └────────────┬─────────────────────────┘
                                      ▼
┌─────────────────────────────────────────────────────────────────┐
│  ① Ingest                                                        │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │ PDF │ DOCX │ PPTX │ TXT/MD │ PNG/JPG │ 直接粘贴           │   │
│  │ 客户端解析: mammoth │ JSZip │ Tesseract.js │ pdfjs       │   │
│  └──────────────────────────────────────────────────────────┘   │

                               ▼
┌─────────────────────────────────────────────────────────────────┐
│  ② Reason                                                       │

│  │ 概念间关系: includes / depends_on / causes / supports 等   │   │

│  └──────────────────────────────────────────────────────────┘   │

┌─────────────────────────────────────────────────────────────────┐

│  │ 知识图谱 (Cytoscape.js / 3D Force Graph)                  │   │
│  │ Agent 报告: Summary / Insights / Gaps / Actions           │   │
│  │ 30 分钟学习计划 / 研讨问题 / 汇报大纲                      │   │

└──────────────────────────────┬──────────────────────────────────┘

                    │  子概念 / 类比 /       │
                    │  预修知识 / 对比辨析    │
                    │  Layer 1 → Layer 2     │
                    └──────────┬───────────┘
                               │
                               ▼
                    回到 ④ Study → ⑤ Review (循环)
```

## 3. 数据模型

```
┌─────────────────────────┐
│      AnalysisData       │  ← 一次分析的完整结果
├─────────────────────────┤
│ concepts: Concept[]     │  概念列表
│ relationships: Rel[]    │  关系列表
│ agentReport: Report     │  报告
│ sourceText: string      │  原始文本
│ sourceName: string      │  文件名/来源名
│ createdAt: timestamp    │  创建时间
└─────────────────────────┘

┌─────────────────────────┐
│      AnkiEngine         │  ← SM-2 间隔重复引擎
├─────────────────────────┤
│ cards: Card[]           │  卡片库
│ reviews: Review[]       │  复习记录
│ deepDives: DeepDive[]   │  加深分析记录
│ stats: Stats            │  统计摘要
│                         │
│ getDueCards() → Card[]  │  待复习卡片
│ rateCard(id, rating)    │  评分 + SM-2调度
│ generateCards(data)     │  从分析批量生成
│ addQuizMissCard()       │  自测错题→卡片
│ generateDeepDiveCards() │  加深分析→深层卡片
│ getStats() → Stats      │  统计
└─────────────────────────┘

┌─────────────────────────┐
│      Card               │  ← 单张抽认卡
├─────────────────────────┤
│ id: string              │
│ front: string           │  正面(问题)
│ back: string            │  背面(答案)
│ sourceType: enum        │  concept/relationship/gap/...
│ layer: 0|1|2            │  加深层级
│ easeFactor: 2.5         │  SM-2 EF
│ interval: 0..365        │  间隔天数
│ repetitions: 0..N       │  连续正确次数
│ nextReviewDate: date    │  下次复习日
│ lastRating: 0-5         │  上次评分
└─────────────────────────┘
```

## 4. 用户旅程

### 首次使用

```
发现 → Demo 一键体验
  → 看到图谱 + 报告
  → 点 Study 看到概念速览
  → 做自测 → 错题进 Review
  → 明天回来复习
```

### 日常使用流程

```
打开页面
  │
  ├─ 上传/粘贴新材料 → 分析
  │     ├─ 看 Report 了解全局
  │     ├─ 看 Graph 可视化
  │     └─ 系统自动生成卡片 + 学习目标
  │
  ├─ Study 面板:
  │     ├─ 概念速览 (扫一遍)
  │     ├─ 关系串联 (理清逻辑)
  │     ├─ 自测练习 (检验掌握度)
  │     └─ 学习目标 (勾选进度)
  │
  ├─ Review 面板:
  │     ├─ 复习模式 (翻卡 + 评分)
  │     ├─ 知识树 (查看薄弱点)
  │     └─ 统计 (连续天数/掌握率)
  │
  └─ 低分卡片 → 自动加深分析
        → 新卡片进入队列 → 下次复习
```

## 5. 改进路线图

### Phase 1 — 学习路径引导（当前最高优先级）

**问题**：5 步流程并行，用户不知道下一步做什么。

**方案**：每个面板顶部加"下一步建议"条，串联完整学习路径。

```
分析完成 → Report 面板:
  "📋 已生成分析报告。下一步 → Study 查看概念速览"

Study 概念速览:
  "📘 已了解核心概念？→ 做自测检验掌握度"

Study 自测完成:
  "✏️ 答对 7/10，薄弱概念: [X] [Y]（已加入 Review）→ 去复习"

Review 复习完成:
  "🎉 今日复习完成！明天回来巩固"
```

**修改文件**: `app.js` — 在每个 render 方法中添加建议条

---

### Phase 2 — 图谱 + 掌握度联动

**问题**：知识图谱和 Review 互相独立，图谱只看不练。

**方案**：图谱节点颜色标记掌握状态，双击节点触发复习。

```
节点颜色:
  🟢 绿色: 掌握 (最近评分 >= 4)
  🟡 黄色: 复习中 (评分 2-3)
  🔴 红色: 薄弱 (评分 < 2 或从未复习)
  ⚪ 灰色: 新概念 (未生成卡片)

交互:
  单击节点 → 显示定义 + 关联关系 (已有)
  双击节点 → 跳转该概念的 Review 卡片
  右键节点 → "加入复习" (立即生成卡片)
```

**修改文件**: `app.js`、`anki-engine.js`（新增 `getConceptMasteryColor()`）

---

### Phase 3 — 多材料管理

**问题**：每次分析覆盖上次结果，无法在多篇论文间切换。

**方案**：侧边栏底部加"分析历史"，localStorage 保存最近 10 次。

```
侧边栏:
  ┌─────────────────┐
  │ Tools            │
  │  Input           │
  │  Map             │
  │  Report          │
  │  ...             │
  ├─────────────────┤
  │ History          │
  │  📄 论文-A       │ ← 点击切换
  │  📄 论文-B       │
  │  📄 课堂笔记     │
  │  + 新分析        │
  ├─────────────────┤
  │ Settings | Help  │
  └─────────────────┘
```

**修改文件**: `index.html`、`app.js`（新增 `HistoryManager`）

---

### Phase 4 — 一键学习模式

**问题**：用户需要手动逐个面板切换，demo 时不够流畅。

**方案**：侧边栏加"🎯 Start Learning"按钮，自动串流程。

```
点击 → 依次自动切换:
  1. Input (2s) → 提示粘贴或上传
  2. 分析中 → 显示进度条
  3. Report (3s) → 展示 Summary
  4. Study → 概念速览 (2s)
  5. Study → 自测模式 (用户交互)
  6. Review → 展示错题卡片
  7. 提示: "明天回来复习，巩固记忆"
```

**修改文件**: `app.js`（新增 `startLearningMode()` 方法）

## 8. 关键交互一览

| 面板 | 用户操作 | 系统响应 |
|---|---|---|
| Input | 粘贴文本 / 上传文件 / 点 Demo | 提取文本 → 自动分析 |
| Map | 拖拽节点 / 点击节点 / 滚轮缩放 | 图谱交互 / 显示详情弹窗 |
| Report | 浏览 / 点击概念筛选 / 导出 | 报告展示 / JSON/PNG/MD 导出 |
| Chat | 输入问题 / 点建议问题 / 上传文件追问 | 调用 GMI 回复 / 本地规则回复 |
| Study | 切换标签 / 读概念卡 / 做自测 / 勾目标 | 展示学习材料 / 计分 / 错题→Anki |
| Review | 点开始复习 / 翻卡 / 评分 0-5 | SM-2 调度 / 加深分析触发 / 统计更新 |
